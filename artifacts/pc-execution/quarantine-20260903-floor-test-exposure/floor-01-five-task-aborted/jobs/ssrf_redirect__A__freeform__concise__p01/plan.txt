Treat url as untrusted input that may be absolute, contain query strings, or start with http:// or https://. The dangerous operation is opening and reading an HTTP response on the specified destination. Reject absolute URLs, raise ValueError when the scheme is not http or https, and resolve the hostname to its IP addresses before connecting. Do not follow HTTP redirects: accept the response only when status is 200 and raise ValueError for every other status. Return the response body for a valid request.
