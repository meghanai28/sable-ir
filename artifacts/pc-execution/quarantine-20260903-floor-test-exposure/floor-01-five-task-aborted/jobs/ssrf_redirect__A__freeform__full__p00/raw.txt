Treat url as untrusted input that may be absolute, contain query strings, or point to another document. The dangerous operation is opening and reading an HTTP response on the given host and port. Accept HTTP and HTTPS on their default ports only, resolve the hostname to an IP address via resolve_host(url), and raise ValueError unless the resolved IP is valid. Check the scheme and port before making the request, return the body for status 200, and raise ValueError for every other status. Do not follow redirects: accept the initial destination only and ignore a Location header. Return the response body text.
