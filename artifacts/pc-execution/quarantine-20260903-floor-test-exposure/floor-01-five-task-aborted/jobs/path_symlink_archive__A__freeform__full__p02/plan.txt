The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute, contain .. segments, or name a symbolic link. The dangerous operation is extracting a tar archive. Reject symbolic links and hard links inside the archive, even those whose declared targets remain inside dest_path; a symbolic link whose target stays inside the destination must still be rejected. Do all validation before opening or writing any file from the archive. Return True only when the extraction completes successfully; on validation failure or a non-zero exit, do not write any archive member outside dest_path and return False.
