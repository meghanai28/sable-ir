SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to any host
SINK: opening an HTTP connection and reading the response body
GUARD: accept only HTTP or HTTPS on the default port; resolve the hostname and raise ValueError unless an IP address is returned; follow the response only when status is 200 and raise ValueError for every other status; do not follow redirects
ORDER: resolve_host before opening the connection; check status before reading the body
EFFECT: return the response body text for a successful request
END_PLAN
