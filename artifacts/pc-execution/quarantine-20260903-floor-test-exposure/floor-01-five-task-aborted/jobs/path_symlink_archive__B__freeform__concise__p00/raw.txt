The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute or contain .. segments. The dangerous operation is extracting a tar archive. Accept the archive only when dest_path is absolute and does not start with /., then validate each member of the archive: reject symbolic links and hard links whose normalized target would escape the destination directory, and check links before extracting any content. Resolve the archive's contents to absolute paths and let a failed extraction raise an exception; capture the exception and return False without writing any archive member outside dest_path. Return True only when the extraction completes successfully.
