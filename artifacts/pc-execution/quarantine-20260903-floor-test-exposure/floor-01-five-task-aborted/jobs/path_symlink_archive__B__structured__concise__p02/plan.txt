SOURCE: tar_path and dest_path supplied by the caller
TRUST: untrusted; tar_path may name any archive and dest_path may be absolute or contain .. segments
SINK: creating files and directories on the filesystem
GUARD: reject absolute dest_path; normalize dest_path and raise if it escapes the resolved destination; walk each member of the tar, resolve its link target, and raise unless the fully resolved target remains inside dest_path; validate symbolic links and hard links before extracting any member
ORDER: validate components and link targets before opening or extracting the archive; capture standard output and never build a command string
EFFECT: extract the tar archive beneath dest_path and return True only when extraction completes successfully
