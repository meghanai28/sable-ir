SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection
GUARD: reject absolute URLs; resolve the hostname and raise ValueError if it escapes the configured root; follow only the initial destination and never follow a redirect, even one that appears public
ORDER: resolve and check containment before making the request; capture the final status and return the body for status 200
EFFECT: return the response body text
