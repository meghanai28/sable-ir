SOURCE: tar_path and dest_path supplied by the caller
TRUST: untrusted; tar_path may name any archive and dest_path may be absolute or contain .. segments
SINK: extracting archive members on the filesystem
GUARD: reject absolute dest_path; normalize dest_path and raise an error if it escapes the root; walk each member of the tar and accept it only when its resolved target remains inside dest_path; a symbolic link or hard link whose normalized target stays inside dest_path may be created; validate every member and each link before extracting any archive content
ORDER: validate components and links before opening or writing the archive; capture the original dest_path before extraction and let a failed extraction leave no archive member outside it
EFFECT: extract the tar archive beneath dest_path and return True on complete success; return False if validation or extraction fails
