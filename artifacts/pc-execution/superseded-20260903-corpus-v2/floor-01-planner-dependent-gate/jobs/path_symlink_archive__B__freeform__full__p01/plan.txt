The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute or contain .. segments. The dangerous operation is extracting a tar archive. Accept the archive only when dest_path is absolute and does not start with /., then normalize the requested extraction root and reject it if it escapes the filesystem. Walk each member of the archive, resolve its link targets, and accept symbolic links and hard links only when every normalized link target remains inside the validated destination; a link whose target escapes must be rejected before any extraction occurs. Do all of this validation before opening or writing any archive content. Return True only when the entire archive has been extracted successfully; a failed validation or extraction must return False and must not have written any archive member outside dest_path.
