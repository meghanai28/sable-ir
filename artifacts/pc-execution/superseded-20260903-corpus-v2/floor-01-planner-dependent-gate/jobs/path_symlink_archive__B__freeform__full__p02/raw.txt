The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute, contain .. segments, or name a symbolic link. The dangerous operation is extracting a tar archive. Accept the archive only when dest_path is absolute and does not start with /., and walk each member of the archive, resolving its normalized target beneath dest_path; reject symbolic links and hard links whose resolved target escapes the destination. Validate every member and each link before extracting any archive content, and let a validation or extraction failure return False without writing any archive member outside dest_path. Return True only when the extraction completes successfully.
