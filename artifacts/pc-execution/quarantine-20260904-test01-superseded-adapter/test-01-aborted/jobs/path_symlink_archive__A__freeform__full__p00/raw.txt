The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute, contain .. segments, or name a symbolic link. The dangerous operation is extracting a tar archive on the filesystem. Reject absolute dest_path, normalize the destination and raise an error if it escapes the resolved dest_path, and walk each member in the archive, following symbolic links and hard links, and raise an error unless every member is a regular file or directory; a symbolic or hard link whose declared target remains inside the destination must be rejected even if it appears to stay inside. Do all of this validation before opening or extracting the archive, and return True only when the entire archive has been extracted successfully. Return False unless the complete extraction completes.
