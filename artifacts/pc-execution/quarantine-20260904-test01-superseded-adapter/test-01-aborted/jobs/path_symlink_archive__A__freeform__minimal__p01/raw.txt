The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may name any directory. The dangerous operation is extracting the tar archive. Reject every symbolic-link and hard-link member in the archive, even one whose declared target would remain inside dest_path; regular files and directories may be extracted. Resolve dest_path and fail if it is absolute. Check each member before extracting it, and let a failed check cause extraction to be aborted with no archive member written outside dest_path. Return True only when the archive is fully extracted; return False when validation or extraction fails.
