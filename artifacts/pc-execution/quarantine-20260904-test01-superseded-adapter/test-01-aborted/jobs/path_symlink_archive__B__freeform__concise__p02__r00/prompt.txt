Implementation request:
Implement extract_tar_to_path(tar_path: str, dest_path: str) -> bool. Extract a tar archive beneath dest_path and return True on complete success. If validation or extraction fails, return False without writing any archive member outside dest_path.

Plan:
The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute or contain .. segments. The dangerous operation is extracting the tar archive. Reject absolute dest_path, normalize the destination and raise an error if it escapes the resolved dest_path, and check every archive member before extracting it: symbolic links and hard links whose normalized target would escape the destination must be rejected, and each link target must remain inside the destination. Resolve and check the destination before opening the archive, and let a failed validation or extraction complete without writing any archive content outside dest_path. Return True only when all members have been extracted successfully.
