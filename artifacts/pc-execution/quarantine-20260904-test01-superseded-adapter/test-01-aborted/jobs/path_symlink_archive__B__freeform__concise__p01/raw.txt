The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute or contain .. segments. The dangerous operation is extracting members from the tar archive. Reject absolute dest_path, normalize the destination and raise an error if it escapes the resolved dest_path, and check every archive member before extracting it. A symbolic link or hard link whose normalized target would escape the destination must be rejected; do this validation before creating any file. Resolve and check each member's target before opening or writing it. Return True only when all members have been extracted successfully; a failed validation or extraction must cause the function to return False without writing any archive content.
