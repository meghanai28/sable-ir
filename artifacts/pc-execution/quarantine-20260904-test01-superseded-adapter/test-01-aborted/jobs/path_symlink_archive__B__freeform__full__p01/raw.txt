The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute or contain .. segments. The dangerous operation is extracting members from the tar archive. Reject absolute dest_path, normalize the destination and raise an error if it escapes the resolved dest_path, and check every archive member before extracting it: symbolic links and hard links whose resolved target would escape the destination must be validated and rejected, and each link target must remain inside the destination. Resolve and check the link targets before extracting any archive content, and let a validation or extraction failure return False without writing any member outside dest_path. Return True only when the entire archive has been extracted successfully.
