Implement extract_tar_to_path(tar_path: str, dest_path: str) -> bool. Extract a tar archive beneath dest_path and return True on complete success. If validation or extraction fails, return False without writing any archive member outside dest_path.

Reject absolute dest_path, normalize the destination and raise an error if it escapes the resolved dest_path, and walk each member of the archive, following symbolic links and hard links, and reject every symbolic link or hard link whose target, even if declared inside the archive, would remain inside the destination.
