The caller-supplied tar_path and dest_path are untrusted: tar_path points to the archive and dest_path is the extraction destination. The dangerous operation is opening and extracting a tar archive. Reject every symbolic-link and hard-link member, including links whose declared targets appear to remain inside dest_path; a symbolic-link whose target is absolute or whose resolved target escapes the resolved dest_path must be rejected even if the target does not currently exist. Regular files and directories may be extracted. Resolve the destination before extracting any members and check each member's link type and resolved target before writing it. Return True only when the archive is fully extracted; validation or extraction failure must return False and must not have written any archive member outside dest_path.
