SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to any host
SINK: opening and reading an HTTP response
GUARD: accept only HTTP or HTTPS on the default port; resolve the hostname and raise ValueError if resolution fails; follow the initial destination but never follow a redirect, even one that appears public; check the final destination before reading the body and raise ValueError when it is not on the same scheme and default port as the requested url
ORDER: resolve the host before opening the connection; capture the initial response status and headers, then reject every redirect response without following its Location value; read the response body only for a 200 status
EFFECT: return the response body text
