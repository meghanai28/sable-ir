The caller-supplied url may be absolute or relative and may contain a location header. The dangerous operation is opening and reading an HTTP connection. Resolve the destination hostname using resolve_host and check the scheme: accept only http or https on its default port and raise ValueError for every other scheme. Resolve each Location header supplied by the transport, following at most five hops, and each resolved Location must have the same scheme, port, credentials, DNS, and public address as the initial destination; raise ValueError unless this holds. Check the scheme and hop limit before opening the connection, and return the body of a successful request whose status is exactly 200.
