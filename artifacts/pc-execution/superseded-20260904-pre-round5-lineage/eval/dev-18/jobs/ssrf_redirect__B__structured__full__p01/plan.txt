SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point outside the target host
SINK: opening and reading an HTTP connection
GUARD: reject absolute URLs; resolve the hostname and raise ValueError unless it resolves to an IP address; follow at most five HTTP redirects; each Location header must be resolved against the current URL and must have the same scheme, port, credentials, and DNS as the initial destination; resolve and check the destination before opening the connection; check scheme and resolve/IP before creating the transport
ORDER: resolve_host and complete redirect resolution before opening the connection; capture the initial scheme/port/credentials and validate each subsequent Location against them
EFFECT: return the body text of the validated request only
