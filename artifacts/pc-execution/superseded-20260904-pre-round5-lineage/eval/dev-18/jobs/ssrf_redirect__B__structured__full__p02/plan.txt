SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point outside the target
SINK: opening and reading an HTTP connection
GUARD: accept only HTTP or HTTPS on the default port, resolve the hostname and raise ValueError if it cannot be resolved, and resolve the requested URL against the current URL, following at most five Location hops; each Location must have the same scheme and port as the initial destination and must pass DNS and public-address validation
ORDER: resolve and check components before establishing the connection; check the resolved destination before following any Location
EFFECT: return the body text of the resolved URL whose status is 200
