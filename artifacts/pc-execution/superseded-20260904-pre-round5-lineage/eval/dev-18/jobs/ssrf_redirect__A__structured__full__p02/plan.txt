SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to any host
SINK: opening and reading an HTTP response
GUARD: accept only HTTP or HTTPS on the default port and raise ValueError for every other scheme; resolve the target's hostname and raise ValueError unless resolve_host returns textual IP addresses; follow the Location header only when it is relative and the complete resolved destination remains beneath the selected public destination; reject every redirect response, even one that appears public
ORDER: check the scheme and resolve the hostname before making the network request; capture the final resolved destination and check it before following a relative Location
EFFECT: return the body of the validated response for status 200
