SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point outside the target
SINK: opening and reading an HTTP response
GUARD: reject absolute URLs; resolve the requested hostname and raise ValueError unless it resolves to a finite IP address; resolve each Location header in the response chain, stop after five hops, and raise ValueError if a Location has no scheme, uses a different scheme/port, or resolves to an IP address that does not match the DNS entry for the current host's public address; check the resolved destination before following any redirect
ORDER: resolve and check the destination before starting the transport; after each redirect, resolve and check the next destination
EFFECT: return the body of the validated request's 200 response only
END_PLAN
