SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to any host
SINK: opening and reading an HTTP response
GUARD: accept only HTTP or HTTPS on the default port; resolve the hostname and raise ValueError if resolution fails; follow at most five Location hops; each Location must be resolved against the current URL and must have the same scheme, port, credentials, DNS, and public address as the initial destination; capture the final resolved URL and check that it remains beneath the requested base path
ORDER: resolve the hostname before opening the connection; process Location headers and check each hop before reading the body; return the response body only for status 200
EFFECT: return the text body of the validated request
