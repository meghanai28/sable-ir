Treat url as untrusted input that may be absolute, contain query strings, or point to any host. The dangerous operation is opening and reading an HTTP response on the specified host and port. Accept only HTTP and HTTPS on their default ports (80 and 443) and raise ValueError for every other scheme or port. Resolve the target hostname using resolve_host and check the resolved IP before establishing the connection; a resolved address outside the allowed scheme/port combination is invalid. Return the response body for status 200 and raise ValueError for every other status. Do all of this validation before opening the connection, and let the caller-supplied transport provide status, headers, and body.
