SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or be relative
SINK: opening and reading an HTTP connection
GUARD: reject absolute URLs; resolve the hostname and raise ValueError unless it resolves to a finite IP address; resolve the requested URL and follow at most five Location hops, resolving each Location against the current URL and checking scheme, port, credentials, DNS, and public address for every hop; raise ValueError unless the final resolved destination has scheme http or https on its default port and return the body only for status 200
ORDER: resolve and check components before establishing the connection
EFFECT: return the response body text for a validated request
END_PLAN
