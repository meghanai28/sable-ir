SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to any host
SINK: opening and reading an HTTP response
GUARD: reject absolute URLs; resolve the target's host and raise ValueError unless it is reachable; follow only the initial request and raise ValueError for every redirect, regardless of the Location value
ORDER: check components before opening the connection; capture the initial status and headers, then never follow redirects
EFFECT: return the body of the initial 200 response only
