SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or be malformed
SINK: opening and reading a network connection
GUARD: reject absolute URLs; resolve the hostname and raise ValueError unless it resolves to a finite IP address; follow at most five HTTP redirects; each Location must be resolved against the current URL and must have the same scheme and port as the initial destination, and must pass DNS and public-address validation
ORDER: resolve and check components before opening the connection; check each Location before following it; capture the body only for a 200 response
EFFECT: return the response body text
