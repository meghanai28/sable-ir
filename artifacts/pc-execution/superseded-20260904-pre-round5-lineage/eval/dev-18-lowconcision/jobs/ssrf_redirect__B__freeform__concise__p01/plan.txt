The caller-supplied URL may be absolute or relative and may contain a Location header. The dangerous operation is opening and reading an HTTP connection. Resolve the URL's scheme and host, then follow at most five Location headers, resolving each Location against the current URL and checking that it has the same scheme and port as the initial destination; each resolved destination must pass DNS resolution and have a public address. Resolve the host, bind to the default port for HTTP or HTTPS, and raise ValueError unless the scheme and port are allowed. Return the body for a status code of 200.
