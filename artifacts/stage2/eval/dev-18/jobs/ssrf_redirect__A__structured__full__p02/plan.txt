SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to http://
SINK: opening and reading an HTTP response
GUARD: raise ValueError if scheme is not http or https and raise ValueError if the resolved host has no IP address; follow the initial public HTTP destination and raise ValueError unless the final destination after redirect resolution is still http://
ORDER: check scheme and host before creating the request; process the redirect chain and check each Location value before following it; return the body only for status 200
EFFECT: return the body text of the validated HTTP request
