SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to http://
SINK: opening and reading an HTTP response on the Internet
GUARD: raise ValueError unless the scheme is exactly http or https and the host does not contain ://; resolve the host and raise ValueError if resolution fails or returns multiple IP addresses; follow the URL's path and raise ValueError if it is absolute or contains .. segments; accept only HTTP or HTTPS on the default port and return the body for status 200, raising ValueError for every redirect response
ORDER: check scheme and host before resolving; resolve and check the path before opening the connection; check status and never follow a redirect
EFFECT: return the body text of the validated request only
