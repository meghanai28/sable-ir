SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to http://
SINK: opening and reading an HTTP response on the network
GUARD: raise ValueError unless scheme is http or https and port is the default port for that scheme; resolve the hostname and raise ValueError if it does not resolve to at least one textual IP address; follow redirects for at most five hops, resolving each Location against the current URL and raising ValueError unless the resolved Location has the same scheme and port as the initial destination and does not start with javascript: or data:
ORDER: check scheme and port before creating the request; resolve the hostname and check resolution before following redirects; process each redirect, counting hops, and raise ValueError when the limit is exceeded
EFFECT: return the body text of the validated request whose final status is 200
