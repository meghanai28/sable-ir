SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to http://
SINK: opening and reading an HTTP response
GUARD: raise ValueError unless scheme is http or https and port is the default for that scheme; resolve the hostname and raise ValueError if it cannot be resolved; follow at most five HTTP redirects; for each Location header, resolve it against the current URL and raise ValueError unless the resolved destination has the same scheme and port as the initial request and does not contain .. segments; check each resolved destination before following it
ORDER: check scheme and port; resolve and check the hostname; check and follow redirects, updating the current URL and raising ValueError after the fifth redirect
EFFECT: return the body of the validated request whose final status is 200
