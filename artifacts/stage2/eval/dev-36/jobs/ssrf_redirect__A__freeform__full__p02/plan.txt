The caller-supplied url may be absolute or relative and may redirect; treat it as untrusted input whose destination and components are not trusted. The dangerous operation is opening and reading an HTTP connection on the default port for HTTP or HTTPS. Resolve the hostname to its IP address(es) via resolve_host(hostname) and raise ValueError unless exactly one IP address is returned. Check the scheme of url and raise ValueError unless it is http or https. Resolve the initial destination and raise ValueError unless the resolved hostname has a valid IP address. Check the scheme and path of the initial destination and raise ValueError unless the path is absolute and does not start with .. segments. Follow the location of a redirect only when the redirect's Location value is absolute and does not start with .. segments; resolve and check each redirect's Location the same way as the initial destination and raise ValueError unless it is absolute and free of .. segments. Do not follow a redirect whose Location is relative or whose resolved destination would be outside the resolved initial destination. Check the status of the final destination and raise ValueError unless it is exactly 200. Return the body of the final destination whose status is exactly 200.
