SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection on the specified host and port and reading the response body
GUARD: normalize and resolve the requested hostname to its textual IP address(es) before creating the connection; raise ValueError if resolution fails
check the requested port and raise ValueError unless it is 80 for HTTP or 443 for HTTPS
follow the initial Location of a redirect only when the new destination's scheme and host remain within the same scheme and root as the requested URL; raise ValueError if the redirect escapes the scheme or root
return the response body only when the status code is exactly 200 and raise ValueError for every other status
EFFECT: return the validated response body for status 200
ORDER: resolve_host and check the port before opening the connection; follow the initial Location and check it before following the redirect; check the status code and raise ValueError unless it is exactly 200
