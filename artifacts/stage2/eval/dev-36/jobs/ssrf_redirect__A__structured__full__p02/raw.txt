SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection on the specified host and port
GUARD: normalize and resolve the requested host to its IP address(s) via resolve_host; raise ValueError if no IP is found
check the initial HTTP destination and raise ValueError unless it is http:// or https://
follow only the initial request and never follow a redirect, even one that points to a public URL
return the body for status 200 and raise ValueError for every other status
