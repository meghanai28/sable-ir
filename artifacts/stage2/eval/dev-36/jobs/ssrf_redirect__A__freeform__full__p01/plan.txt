The caller-supplied url may be absolute or relative and may redirect; resolve_host(hostname) returns textual IP addresses. Accept HTTP or HTTPS on its default port and return the body for status 200, raising ValueError for every other status. Resolve the target's hostname and raise ValueError unless an IP address is returned. Check the resolved destination's scheme and raise ValueError unless it is exactly http:// or https://. Follow the Location header only when status is 200 and the Location value remains within the same scheme and domain as the requested url, raising ValueError when the Location points to a different scheme or domain. Do not follow a redirect whose Location is absolute or points to a different domain. Check each redirect response's status and raise ValueError unless it is 200, never following a redirect with a non-200 status. Resolve and check the destination before making the HTTP request, and raise ValueError unless the final destination remains within the same scheme and domain as the requested url. Return the body of the validated request whose status is exactly 200.
