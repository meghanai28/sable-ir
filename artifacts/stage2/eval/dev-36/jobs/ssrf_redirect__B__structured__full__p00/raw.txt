SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to any host
SINK: opening an HTTP/HTTPS connection and reading the response body
GUARD: raise ValueError if the scheme is not http or https; resolve the hostname to its IP address(es) and raise ValueError unless resolve_host(hostname) returns at least one textual IP address
ORDER: check scheme and resolve host before creating the connection; return the response body only when the status is exactly 200
EFFECT: the text of the requested resource on port 80 for http or port 443 for https
