The caller-supplied url may be absolute or relative and may contain a Location header whose value is untrusted: it can be absolute, contain .. segments, or be absolute with scheme http://. The dangerous operation is opening and reading an HTTP response on the provided url. Raise ValueError if the scheme is not http:// or https:// and raise ValueError if the requested port is not the default port for the scheme (80 for http, 443 for https). Resolve the url's hostname to its textual IP address(es) using resolve_host and raise ValueError when no IP address is found. Follow at most five HTTP redirects, resolving each Location header against the current URL and raising ValueError if a Location is absolute with a scheme other than http:// or https://, has a port other than the default for its scheme, or points to a DNS name whose resolved IP address does not share the same scheme and port as the initial destination. Resolve the final destination's hostname and raise ValueError when no IP address is found. Return the body of the resolved destination whose status is exactly 200.
