Plan:
The caller-supplied url may be absolute or relative and may contain a Location header whose value is untrusted: it can be absolute, contain .. segments, use JavaScript protocol, or be out of range. The dangerous operation is opening and reading an HTTP response on the provided url. Raise ValueError if the scheme is not http or https and raise ValueError if the requested port is not the default port for the scheme (80 for http, 443 for https). Check the status code of the final response and raise ValueError unless it is exactly 200, then return the response body as text.
