The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute, contain .. segments, or name a symbolic link. The dangerous operation is extracting an archive's contents on the filesystem. Normalize the requested destination and raise an error if it escapes the resolved root of dest_path, then walk each member of the tar archive, following symbolic links and resolving their targets, and raise an error unless the fully resolved target of every symbolic link and hard link remains inside dest_path. Do all of this validation before extracting any archive content, and return False if validation or extraction fails, never writing a member outside dest_path. Return True only when the archive is completely extracted and all members stay inside dest_path.
