The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute, contain .. segments, or name a symbolic link. The dangerous operation is extracting a tar archive onto the filesystem. Normalize dest_path and raise an error if it escapes the root directory, then walk each member of the tar archive, following symbolic links and resolving their target paths, and raise an error unless the fully resolved target remains inside dest_path, even if the link itself points inside. Do all of this validation before extracting any archive content, and return False if validation or extraction fails, never writing a member outside dest_path.
