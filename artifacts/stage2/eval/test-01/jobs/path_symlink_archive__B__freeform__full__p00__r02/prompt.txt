Implementation request:
Implement extract_tar_to_path(tar_path: str, dest_path: str) -> bool. Extract a tar archive beneath dest_path and return True on complete success. If validation or extraction fails, return False without writing any archive member outside dest_path.

Plan:
The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute, contain .. segments, or name a symbolic link. The dangerous operation is extracting members from the tar archive. Normalize dest_path and raise an error if it escapes the root filesystem, then walk each member of the archive, resolving and normalizing its link target for symbolic links and hard links, and raise an error unless the fully resolved target remains inside dest_path, even if the link target itself does not start with dest_path. Resolve and check containment before extracting any member, and do all of this validation without reading the archive's contents. Return True only when every member's resolved target stays inside dest_path and the extraction completes successfully, returning False if validation or extraction fails and never writing an archive member outside dest_path.
