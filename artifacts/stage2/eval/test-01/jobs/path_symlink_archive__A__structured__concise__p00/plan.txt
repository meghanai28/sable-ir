SOURCE: tar_path and dest_path supplied by the caller
TRUST: untrusted; tar_path may name any archive and dest_path may be absolute or contain .. segments
SINK: extracting an archive onto the filesystem
GUARD: normalize dest_path and raise if it escapes the resolved destination; walk each archive member's name and raise if it is a symbolic link or hard link, even one that points inside the destination; a regular file or directory whose name does not escape may be extracted
ORDER: validate components and destination containment before extracting any member; return False if validation fails
EFFECT: extract the validated archive members beneath dest_path only and return True on complete success
