The caller-supplied tar_path and dest_path are untrusted: tar_path may name any archive and dest_path may be absolute, contain .. segments, or name a symbolic link. The dangerous operation is extracting a tar archive onto the filesystem. Normalize dest_path and raise an error if it escapes the resolved root of dest_path, then walk each archive member's name and raise an error if its absolute path, with symbolic links followed, escapes the resolved root of dest_path, even when the declared target appears to remain inside dest_path. Do all of this validation before extracting any member of the archive, and return False if validation fails. Return True only when validation and extraction complete successfully without writing any archive member outside dest_path.
