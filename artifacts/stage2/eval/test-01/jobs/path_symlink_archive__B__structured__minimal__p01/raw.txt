SOURCE: tar_path and dest_path supplied by the caller
TRUST: untrusted; tar_path may name any archive and dest_path may be absolute or contain .. segments
SINK: extracting an archive file on the filesystem

ORDER: validate components and the archive before extracting; return False if validation fails
EFFECT: extract the tar archive beneath dest_path only when all checks pass
RETURN: True on complete success
