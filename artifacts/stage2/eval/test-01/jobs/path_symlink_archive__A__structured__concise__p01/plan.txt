SOURCE: tar_path and dest_path supplied by the caller
TRUST: untrusted; tar may name symbolic links, hard links, or point outside dest_path
SINK: extracting an archive onto the filesystem
GUARD: walk each archive member whose name is absolute or whose resolved target escapes dest_path and raise an error; a symbolic-link or hard-link member whose declared target stays inside dest_path must be rejected
ORDER: check components and resolved target before extracting any member; return False if validation fails
EFFECT: extract only regular files and directories whose resolved target remains inside dest_path
