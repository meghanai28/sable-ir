SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to http://
SINK: initiating an HTTP request to the specified destination
GUARD: raise ValueError if scheme is not http or https; resolve the hostname to its IP address(es) via resolve_host and raise ValueError when no IP is found; follow at most five HTTP redirects, resolving each Location against the current URL and raising ValueError when a Location has the same scheme but a different port, missing credentials, or points to a non-public DNS entry
ORDER: check scheme and resolve the host before making the request; process redirects with a hop limit of five and validate each Location's scheme, port, credentials, and DNS/public-address before following it
EFFECT: return the body of the request whose final status is 200
