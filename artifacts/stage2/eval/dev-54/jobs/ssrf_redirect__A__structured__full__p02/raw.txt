SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection on the specified host and port
GUARD: normalize and resolve the host's IP address via resolve_host, raising ValueError if no IP is found; check the scheme and raise ValueError when the URL does not start with http:// or https://; resolve the initial destination and raise ValueError if it is outside the root /
ORDER: resolve and check the destination before following any redirect; accept only a status of 200 and raise ValueError for every other status
EFFECT: return the body of the validated request whose resolved destination remains beneath the selected root
