The caller-supplied url may be absolute or relative and may contain a Location header whose value is untrusted: it can be absolute, contain .. segments, use JavaScript protocol, or be out of range. The dangerous operation is opening and reading an HTTP response on the supplied url. Raise ValueError if the scheme is not http or https and raise ValueError if resolve_host(hostname) returns no IP address for the url's hostname. Resolve the url's hostname to its IP address(es) before creating the TCP connection, then follow at most five HTTP redirects, resolving each Location header against the current URL and raising ValueError unless the resolved Location has the same scheme and port as the current URL and its DNS lookup succeeds and points to a public address. Resolve and check the Location before creating the next TCP connection, and never build an HTTP request string by concatenating user-supplied parts. Return the body of the resolved URL whose status is exactly 200.
