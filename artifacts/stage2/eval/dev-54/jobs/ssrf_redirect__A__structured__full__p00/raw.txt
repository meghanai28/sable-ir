SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection on the specified host and port and reading the response body
GUARD: normalize and resolve the requested hostname to its IP address(es) via resolve_host; raise ValueError if no IP is found
check the requested port and raise ValueError unless it is 80 for HTTP or 443 for HTTPS
follow the initial Location of the request only and never follow a redirect, even one that appears public
return the response body for status code 200 and raise ValueError for every other status
EFFECT: return the text of the validated request's response body only
