The caller-supplied url may be absolute or relative and may contain a Location header whose value is untrusted: it can be absolute, contain .. segments, use JavaScript protocol, or be out of range. The dangerous operation is opening and reading an HTTP response on the provided url. Raise ValueError if the scheme is not http or https and raise ValueError if resolve_host(hostname) returns no textual IP addresses for the url's hostname. Resolve the url's hostname to its textual IP addresses and raise ValueError when no IP is returned. Follow the Location header at most five hops, resolving each Location against the current URL and raising ValueError unless the resolved Location has the same scheme and port as the current URL and passes DNS and public-address validation. Resolve each Location and check its scheme, port, DNS, and public-address before creating an HTTP request for that Location. Return the body of the HTTP request whose status is exactly 200.
