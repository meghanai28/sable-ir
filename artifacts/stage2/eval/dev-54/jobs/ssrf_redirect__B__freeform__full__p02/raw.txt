The caller-supplied url may be absolute or relative and may contain a Location header whose value is untrusted: it can be absolute, contain .. segments, or be absolute with scheme http://. The dangerous operation is opening and reading an HTTP response on the network. Normalize the requested URL and raise ValueError if it escapes the current effective directory, then follow at most five Location headers, resolving each Location against the current URL and raising ValueError unless the resolved Location remains inside the current effective directory. Each resolved Location must have the same scheme and port as the initial destination and fail validation if its scheme or port does not match. Resolve the hostname of the final destination before making the network request, and raise ValueError unless resolve_host(hostname) returns textual IP addresses. Accept HTTP on port 80 and HTTPS on port 443 only, raising ValueError for every other scheme or port. Return the body of the request whose status is exactly 200 and raise ValueError for every other status. Return the body text of the validated request whose status is exactly 200.
