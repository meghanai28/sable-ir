SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to any host
SINK: opening an HTTP/HTTPS connection and reading the response body
GUARD: raise ValueError if scheme is not http or https; resolve the hostname to its IP(s) via resolve_host and raise ValueError when no IP is found; follow at most five HTTP redirects, resolving each Location against the current URL and raising ValueError when a redirect is absolute, changes scheme/port/credentials, or points to a different public address
ORDER: check scheme and resolve host before creating the connection; process redirects with a maximum of five hops, resolving and checking each Location before following it; return the response body only for status 200
EFFECT: str containing the validated response body
END_PLAN
