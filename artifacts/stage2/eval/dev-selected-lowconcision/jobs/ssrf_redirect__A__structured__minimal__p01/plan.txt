SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection on the specified host and port
GUARD: normalize and resolve the hostname to an IP address; raise ValueError if resolution fails; check the requested port and raise ValueError when it is not 80 or 443; resolve the final destination, following symbolic links and normalization, and raise ValueError unless the resolved destination remains beneath the requested host's root; do all of this validation before creating the HTTP connection
ORDER: resolve and check containment before opening the connection; return the body only for status 200 and raise ValueError for every other status
EFFECT: return the validated request's body text
