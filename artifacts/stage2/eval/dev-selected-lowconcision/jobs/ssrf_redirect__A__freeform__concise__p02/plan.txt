Treat url as untrusted input that is concatenated into an HTTP request and may be absolute, contain query strings, or point to a redirect. The dangerous operation is opening and reading an HTTP connection. Normalize the requested host by resolving it to an IP address through resolve_host(hostname) and raise ValueError unless the resolved IP belongs to the default port for HTTP or HTTPS. Check the requested port and raise ValueError when it is not the default port for HTTP or HTTPS. Follow the initial destination only and never follow a redirect, even one that appears to point to a public URL. Return the body of the request whose status is exactly 200.
