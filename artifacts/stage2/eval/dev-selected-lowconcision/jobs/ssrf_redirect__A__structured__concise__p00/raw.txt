SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection
GUARD: raise ValueError if scheme is not http or https; resolve the hostname to its IP address and raise ValueError unless resolve_host returns at least one IP beneath the requested host's root; follow only the initial HTTP destination and raise ValueError for every redirect response, even one that appears public
ORDER: check scheme and resolve host before creating the connection; do not follow a redirect
EFFECT: return the body of the validated request whose status is exactly 200
