SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection on the default port for HTTP or HTTPS
GUARD: resolve the hostname to its IP addresses and raise ValueError if resolve_host returns no IP; check the initial public HTTP destination and raise ValueError if it does not start with http:// or https://; follow only the initial destination and never follow a redirect, even one that appears public
ORDER: resolve_host and check the destination before creating the connection; return the body for status 200
EFFECT: text of the requested page's body
