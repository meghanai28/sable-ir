SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to a redirect
SINK: opening an HTTP connection and reading the response body
GUARD: resolve the hostname to its IP address and raise ValueError if resolution fails; check the requested scheme and raise ValueError unless it is http or https; resolve the target's final path beneath the configured root and raise ValueError if the resolved path escapes that root
ORDER: resolve_host and check scheme and containment before opening the connection; follow the initial public HTTP destination only and raise ValueError for every redirect response
EFFECT: return the response body for status 200
