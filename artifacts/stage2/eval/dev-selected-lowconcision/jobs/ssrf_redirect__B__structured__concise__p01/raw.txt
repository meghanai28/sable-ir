SOURCE: url supplied by the caller
TRUST: untrusted; may be absolute, contain .. segments, or point to http://
SINK: initiating an HTTP request to the specified destination
GUARD: raise ValueError if scheme is not http or https; resolve the hostname to its IP address and raise ValueError when resolve_host returns no IP; follow at most five HTTP redirects, resolving each Location against the current URL and raising ValueError unless the resolved Location has the same scheme and port as the initial destination and passes DNS and public-address validation
ORDER: check scheme and resolve_host before following redirects; check each resolved Location before navigating to it
EFFECT: return the body of the validated request whose final status is 200
