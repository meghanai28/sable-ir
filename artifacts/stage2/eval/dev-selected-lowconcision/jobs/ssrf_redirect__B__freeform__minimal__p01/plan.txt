Treat url as untrusted input that is concatenated into an HTTP request and whose location header may be absolute or contain query and fragment components. The dangerous operation is opening and reading an HTTP response. Normalize the requested URL and raise ValueError if it escapes the current origin, then follow at most five HTTP redirects, resolving each Location header against the current URL and raising ValueError unless the resolved Location remains within the same origin and has the same scheme and port as the initial destination. Resolve the hostname of the final destination and raise ValueError if resolve_host returns multiple IP addresses. Check the HTTP status code and raise ValueError unless it is exactly 200, then return the response body.
