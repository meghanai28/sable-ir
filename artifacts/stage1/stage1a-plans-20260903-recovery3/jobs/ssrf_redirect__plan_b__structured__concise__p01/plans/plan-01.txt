SOURCE: Untrusted caller-supplied url and Location header values from transport responses.
TRUST: transport and resolve_host are trusted policy-enforced primitives; every url and redirect target is untrusted until validated.
SINK: Invocation of transport(url) to fetch and resolve_host(hostname) for DNS resolution.
GUARD: Allow only HTTP or HTTPS on default ports; validate each hostname with resolve_host for DNS and public-address compliance; follow redirects for at most five hops; resolve every Location against the current URL; apply the same scheme, port, credential, DNS, and public-address validation to each redirect destination; raise ValueError on any disallowed target.
ORDER: Validate the initial url before the first transport call; after any 3xx response, resolve Location against the current url, re-validate, and increment the hop count before the next transport call; return body only upon receiving status 200.
EFFECT: Return the response body as a str when status is 200; raise ValueError for a disallowed initial request, an invalid redirect, or exceeding the hop limit.
END_PLAN
