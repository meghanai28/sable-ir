SOURCE: Caller url, transport, and resolve_host.
TRUST: transport fetches only URLs vetted by this function; resolve_host returns textual IPs.
SINK: Network request via transport and the returned str body.
GUARD: Reject if scheme is not HTTP or HTTPS on default port. Before each request use resolve_host and enforce scheme, port, credential, DNS, and public-address validation identical to the initial destination. Redirects may be followed for at most five hops, but each Location must first be resolved against the current URL and receive the same scheme, port, credential, DNS, and public-address validation as the initial destination. Raise ValueError for any disallowed request.
ORDER: Validate the initial URL and raise ValueError if disallowed. Loop at most five times: invoke transport with the current URL. On status 200 return body. On 3xx with a Location header, resolve it against the current URL, validate the result, and continue. On any other status or missing Location raise ValueError. Exceeding five hops raises ValueError.
EFFECT: Return the response body as str on status 200; raise ValueError for every disallowed, invalid, or exhausted request.
END_PLAN
