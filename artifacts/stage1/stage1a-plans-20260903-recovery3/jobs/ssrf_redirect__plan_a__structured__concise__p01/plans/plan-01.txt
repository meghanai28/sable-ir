SOURCE: Untrusted caller url; accept only http or https on default port.
TRUST: transport and resolve_host are trusted primitives; the url destination is untrusted.
SINK: Return response body str for status 200; raise ValueError for disallowed requests or non-200 statuses.
GUARD: After validating the initial public HTTP destination, reject every redirect response without following its Location value, regardless of whether that new destination also appears to be public.
ORDER: Parse url, validate scheme/port, use resolve_host to check destination, invoke transport, reject any redirect without following Location, return body on 200, else raise ValueError.
EFFECT: Single network fetch; result is either body string or validation exception.
