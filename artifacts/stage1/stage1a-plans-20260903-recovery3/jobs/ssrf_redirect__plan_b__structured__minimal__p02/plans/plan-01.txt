SOURCE: External `url`, caller-supplied `transport`, and caller-supplied `resolve_host`.
TRUST: `url` is untrusted input; `transport` and `resolve_host` are trusted primitives that must only be invoked after validation.
SINK: The `body` string returned to the caller, and the network request issued through `transport`.
GUARD: Validate the parsed URL scheme is `http` or `https` on its default port; reject with `ValueError` if disallowed. Resolve the hostname via `resolve_host` and apply DNS and public-address validation to the returned textual IPs. Preserve clause 5 exactly: "Redirects may be followed for at most five hops, but each Location must first be resolved against the current URL and receive the same scheme, port, credential, DNS, and public-address validation as the initial destination."
ORDER: Parse `url`; validate scheme, port, and resolved IPs; invoke `transport`; if status is 200 return `body`; if status is 3xx, resolve the `Location` against the current URL, re-validate, and re-invoke `transport` up to five hops; raise `ValueError` for any disallowed request or unsupported final status.
EFFECT: Performs host resolution and up to five redirected network requests, returning a `str` body or raising `ValueError`.
