SOURCE: Untrusted tar file at `tar_path`; all member entries (files, directories, symlinks, hard links) read from it.
TRUST: `tar_path` is external/untrusted input; `dest_path` is the trusted root that must strictly contain every extracted object and every resolved link target.
SINK: Filesystem object creation under `dest_path`.
GUARD: Normalize each member's extraction path and reject absolute paths, `..` traversal, and any result outside `dest_path`. Permit symlinks and hard links only when their normalized targets resolve strictly inside `dest_path`.
ORDER: Pre-validate every member path and every link target against the `dest_path` boundary before any filesystem write; perform extraction only if the entire archive passes validation.
EFFECT: Return `True` when the archive is fully extracted beneath `dest_path`. Return `False` if validation or extraction fails; because pre-validation precedes all writes, no archive content is written if validation fails, and no member ever escapes `dest_path`.
