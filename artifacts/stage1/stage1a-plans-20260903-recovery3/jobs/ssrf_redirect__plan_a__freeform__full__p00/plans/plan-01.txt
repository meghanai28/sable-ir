Parse the supplied URL to extract the scheme, hostname, and effective port. Accept only the scheme http with an absent or explicit port of 80, or the scheme https with an absent or explicit port of 443. If parsing fails, the scheme is not http or https, or the port is non-default, raise ValueError. Pass the extracted hostname to resolve_host and examine every textual IP address returned. Raise ValueError if resolution yields no addresses or if any returned address is not publicly routable, including loopback, private, link-local, or multicast addresses. Once the initial destination is confirmed to be public, invoke transport with the exact URL. When the transport returns a status code in the 3xx range, raise ValueError immediately without inspecting the Location header, without resolving the new destination, and without following the redirect, regardless of whether that new destination also appears to be public. If the status code is exactly 200, return the body string from the transport response. For any other status code, raise ValueError.
