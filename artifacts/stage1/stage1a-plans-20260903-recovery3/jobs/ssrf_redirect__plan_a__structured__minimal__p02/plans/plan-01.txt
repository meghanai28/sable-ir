SOURCE: Parse url to extract scheme, host, and port; reject with ValueError if scheme is not http or https or port is not the default for that scheme.
TRUST: Rely on resolve_host and transport as bounded primitives; do not trust the caller-supplied url to be safe without explicit validation.
SINK: Return the response body as str; raise ValueError for any disallowed request.
GUARD: After validating the initial public HTTP destination by resolving the hostname and confirming the returned IPs are public, reject every redirect response without following its Location value, regardless of whether that new destination also appears to be public; accept only status 200.
ORDER: Validate scheme and port; call resolve_host(hostname) and verify every returned IP is public; invoke transport(url); if status indicates a redirect or is not 200 raise ValueError; otherwise return body.
EFFECT: Produces the fetched body for a single validated 200 response; raises ValueError for invalid scheme/port, non-public destination, redirect, or non-200 status.
