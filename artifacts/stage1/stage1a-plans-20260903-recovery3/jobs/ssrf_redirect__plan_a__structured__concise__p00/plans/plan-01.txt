SOURCE: Untrusted `url` argument and return values from `transport` and `resolve_host`.
TRUST: `transport` yields raw status, headers, and body without internally following redirects; `resolve_host` provides accurate textual IPs.
SINK: Invocation of `transport(url)` and subsequent handling of the returned status and body.
GUARD: Parse and validate that the URL scheme is HTTP or HTTPS on its default port; validate the initial public HTTP destination using `resolve_host`; upon response, reject every redirect status without following its Location value, regardless of whether that new destination also appears to be public; only allow status 200 to proceed.
ORDER: Validate destination before calling `transport`; after `transport` returns, inspect status before processing body: redirect statuses raise ValueError immediately, while 200 returns the body.
EFFECT: Returns the response body string for validated 200 responses; raises ValueError for disallowed scheme, port, non-public destination, or any redirect response.
END_PLAN
