Parse the supplied URL and enforce that its scheme is HTTP or HTTPS, its port is the scheme’s default, and it contains no userinfo. Use resolve_host to obtain IP addresses for the hostname; require at least one public IP and reject the request if DNS resolution fails or yields only non-public addresses. Invoke transport with the validated URL. When the response status is 200, return the body. When the status indicates a redirect, follow the Location header for at most five hops; resolve each Location against the current URL and reapply the same scheme, port, credential, DNS, and public-address validation before every subsequent request. Raise ValueError for any validation failure, disallowed destination, non-200 final status, or hop-limit exceeded.
