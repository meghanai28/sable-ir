Parse the supplied url to extract its scheme, hostname, and port. Validate that the scheme is exactly http or https. Validate that the port is the default for the scheme: if the port is omitted, it is implicitly correct; if it is explicitly present, it must be 80 for http or 443 for https. If the scheme is not http or https, or if an explicit non-default port is present, raise ValueError.

Extract the hostname portion and invoke resolve_host(hostname) to obtain the textual IP addresses associated with that host. Ensure the returned collection is non-empty. Examine every returned address and confirm that each one, whether IPv4 or IPv6, is a public, globally routable unicast address. Reject any address belonging to a private, loopback, link-local, multicast, reserved, or otherwise non-public range. If resolve_host returns no addresses, or if any single resolved address is non-public, raise ValueError. This enforces the prerequisite that the initial HTTP destination is public before any network request is issued.

Pass the original url to transport(url) to obtain the tuple (status, headers, body). Evaluate the status code. If status is 200, return body. If status is any 3xx redirect, immediately raise ValueError. Do not read the Location header from headers, do not construct a follow-up url, do not call resolve_host on a redirect target, do not call transport again, and do not evaluate whether the redirected location might be public. The implementation must satisfy the policy that, after validating the initial public HTTP destination, it rejects every redirect response without following its Location value, regardless of whether that new destination also appears to be public. For any status other than 200, including but not limited to 4xx and 5xx errors, raise ValueError.
