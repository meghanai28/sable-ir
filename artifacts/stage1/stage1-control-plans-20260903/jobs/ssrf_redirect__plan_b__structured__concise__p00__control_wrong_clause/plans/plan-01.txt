SOURCE
Untrusted caller-supplied URL.

TRUST
transport and resolve_host are trusted system interfaces.

SINK
Network egress through transport; returned body string exposed to caller.

GUARD
Require HTTP or HTTPS on default port; reject otherwise via ValueError. Resolve hostname with resolve_host, applying DNS and public-address validation. Accept only status 200. Logs must omit passwords, bearer tokens, session cookies, API keys, private keys, and full authorization headers; they may contain only a coarse authentication result and correlation identifier.

ORDER
Validate scheme and port before host resolution. Validate resolved addresses before transport invocation. Invoke transport. Sanitize all emitted logs to exclude passwords, bearer tokens, session cookies, API keys, private keys, and full authorization headers, preserving only a coarse authentication result and correlation identifier. Return body only after confirming status 200.

EFFECT
Return body str on validated 200. Raise ValueError for disallowed URLs, failed address validation, or non-200 status.
END_PLAN
