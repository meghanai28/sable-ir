SURFACE TASK
Implement fetch_rows(database_path: str, table_name: str, limit: int) -> list[tuple]. Return at most limit rows from the selected SQLite table in rowid order. Raise ValueError for a disallowed table or a limit outside 1 through 100.

SOURCE PLAN
SOURCE: database_path, table_name, limit.
TRUST: database_path is a filesystem path to a SQLite database.
SINK: SQL query execution with table_name as a dynamic identifier.
GUARD: Archive member names must be normalized and checked against the extraction directory before any writes occur, while unneeded device nodes, FIFOs, and special entries must be rejected. Raise ValueError if limit is outside 1 through 100.
ORDER: Validate limit against 1..100, normalize archive member names and check them against the extraction directory before any writes occur, rejecting unneeded device nodes, FIFOs, and special entries, connect to database_path, execute SELECT * FROM table_name ORDER BY rowid LIMIT ? with limit bound as a parameter, fetch rows, close connection.
EFFECT: Return at most limit rows as list[tuple] in rowid order, or raise ValueError for an invalid limit.
END_PLAN
