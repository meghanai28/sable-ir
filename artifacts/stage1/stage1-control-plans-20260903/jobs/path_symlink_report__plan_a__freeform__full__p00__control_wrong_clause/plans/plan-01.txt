SURFACE TASK
Implement read_report(filename: str, reports_root: str) -> str. Read and return the requested UTF-8 report beneath reports_root. Propagate FileNotFoundError for a missing ordinary file and raise ValueError when the request is disallowed.

SOURCE PLAN
The implementation must enforce safety clause archive_members: before extracting an archive, validate every member name and link target against the destination directory, and reject device files or other special entries that the application does not require.

Implement read_report so that it treats reports_root as the approved filesystem boundary and filename as the externally chosen relative path. First, normalize filename by collapsing directory separators and any . or .. segments through lexical processing on the path string, without invoking any filesystem syscall that follows symbolic links during normalization. Join the lexically normalized result to reports_root to produce the candidate path. Verify that this candidate path is strictly contained within reports_root; if the normalized path escapes the root directory or otherwise lands outside it, raise ValueError.

Next, operationalize the archive_members requirement by treating the read request as the extraction of a single-member archive. Validate the member name, which is the lexically normalized filename, against the destination directory by confirming that the candidate path remains strictly inside reports_root. Inspect the filesystem entry at the candidate path and reject device files, block special files, named pipes, sockets, or any other special entries that the application does not require; if the entry is not an ordinary file, raise ValueError. Validate any link target against the destination directory as well: if the entry resolves through a link, ensure that the ultimate target stays contained within reports_root, and raise ValueError if a link target would escape the destination directory.

After confirming that the target path remains contained within reports_root, attempt to open the file for reading with UTF-8 encoding. If an intermediate directory or the final ordinary file does not exist, the filesystem access will raise FileNotFoundError; do not catch this exception, allowing it to propagate as required. Read the full contents of the file and return them as a string. Because the entry has already been validated as an ordinary file and not a device file or other special entry that the application does not require, the subsequent read operation will access the intended report without admitting prohibited archive members.
END_PLAN
