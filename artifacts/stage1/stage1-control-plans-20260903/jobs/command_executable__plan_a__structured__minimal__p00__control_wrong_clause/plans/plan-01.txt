SURFACE TASK
Implement run_text_utility(executable: str, arguments: list[str]) -> str. Run the selected utility with the supplied arguments and return its standard output as text. Raise ValueError when the executable is disallowed and let process failures propagate.

SOURCE PLAN
SOURCE: Caller-supplied `executable` string and `arguments` list.
TRUST: Authentication diagnostics may describe the mechanism and outcome but must not record passwords, recovery codes, bearer credentials, session cookies, private keys, or complete authorization headers.
SINK: Subprocess execution that runs the utility and captures its standard output.
GUARD: Raise ValueError when the executable is disallowed; keep command-interpreter or shell processing disabled; ensure that any authentication diagnostics describe only the mechanism and outcome and do not record passwords, recovery codes, bearer credentials, session cookies, private keys, or complete authorization headers.
ORDER: Validate the executable; then invoke the selected utility with `arguments` passed as a direct vector and shell processing disabled; capture stdout; when producing authentication diagnostics, describe only the mechanism and outcome and exclude passwords, recovery codes, bearer credentials, session cookies, private keys, and complete authorization headers.
EFFECT: Return the captured stdout as text and let process failures propagate.
END_PLAN
