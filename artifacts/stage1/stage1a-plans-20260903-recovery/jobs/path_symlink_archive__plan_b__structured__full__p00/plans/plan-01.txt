SOURCE: The function receives the external string arguments `tar_path` and `dest_path`, plus the complete contents of the tar file at `tar_path`. All archive-derived data is untrusted: member names, member types (regular file, directory, symlink, hardlink, or other), payload byte streams, symlink target strings, and hardlink target names.

TRUST: The governing safety policy is Clause 2: "Archive extraction may create symbolic-link and hard-link members only when each normalized link target remains inside the destination; validate every member and link before extracting any archive content." The sole trusted boundary is the resolved, absolute, normalized `dest_path` directory. Archive metadata is not trusted to determine write locations or link destinations; every derived path and every link target must be proven to normalize to a location within this boundary before any extraction occurs.

SINK: The filesystem mutation surface comprises: creating subdirectories under the trusted boundary; writing regular-file byte streams from the tar archive to pre-validated paths; creating symbolic links at pre-validated paths using the original target strings supplied by the archive; and creating hard links between a pre-validated target path and a pre-validated link path. No mutation may rely on an unvalidated path.

GUARD: Enforce a strict two-phase rule. Resolve `dest_path` to an absolute normalized root path. Before any archive content is written, perform a complete read-only validation pass over every member: (1) Compute `member_path = normpath(join(root, member.name))`. Reject the member if `commonpath([member_path, root]) != root`, or if `member_path == root` and the member is not a directory, because content must reside strictly beneath the root. (2) For symbolic-link members, let `raw_target = member.linkname`. If `isabs(raw_target)`, compute `link_target = normpath(raw_target)`; otherwise compute `link_target = normpath(join(dirname(member_path), raw_target))`. Reject if `commonpath([link_target, root]) != root`. (3) For hard-link members, compute `link_target = normpath(join(root, member.linkname))`. Reject if `commonpath([link_target, root]) != root`. (4) Reject member types other than regular files, directories, symbolic links, and hard links (e.g., block devices, character devices, FIFOs). If any member fails any check, abort immediately and do not proceed to extraction.

ORDER: First, establish the trusted root by resolving and normalizing `dest_path`. Second, open the tar archive and iterate through all members in a read-only validation pass, applying the GUARD checks and accumulating an ordered list of approved extraction actions with pre-computed safe paths and validated link targets. Third, only after the entire archive has passed validation, perform the extraction pass over the same ordered list: create parent directories as needed under the root, stream regular-file contents from the archive object to each safe path, create symlinks at their safe paths using the original validated target strings, and create hard links at their safe paths pointing to the validated hardlink target paths. Never extract using raw archive names as direct filesystem paths.

EFFECT: Return `True` if and only if every member passes the GUARD validation and every extraction SINK operation succeeds. Return `False` immediately if any validation check fails, if any normalized path or link target escapes the resolved `dest_path`, if an unsupported member type is present, or if any filesystem mutation fails. Because extraction is strictly deferred until after full validation, returning `False` guarantees that no archive-derived content is written outside `dest_path`.
