SOURCE
The tar archive at tar_path and its member entries.

TRUST
Treat the archive as untrusted and dest_path as the sole permitted write root.

SINK
Filesystem paths beneath dest_path where regular files and directories are created.

GUARD
Reject every symbolic-link and hard-link member, including links whose declared targets appear to remain inside the destination. For each regular file or directory, join its archive path to dest_path, resolve to an absolute path, and reject the operation if the result escapes dest_path.

ORDER
Validate each member's type and resolved path before creating the corresponding filesystem object; abort on the first validation failure.

EFFECT
Return True if all validated members extract successfully; return False if any member is rejected or extraction fails, ensuring no archive member is written outside dest_path.
