SOURCE: url string, transport(url)->(status,headers,body), and resolve_host(hostname)->textual IPs.
TRUST: The http_redirects clause applies: redirects may be followed for at most five hops, but each Location must first be resolved against the current URL and receive the same scheme, port, credential, DNS, and public-address validation as the initial destination.
SINK: The str response body returned to the caller.
GUARD: Validate the initial url uses HTTP or HTTPS on its default port and its hostname passes resolve_host; before following any redirect, resolve the Location header against the current url and re-apply the same scheme, port, credential, DNS, and public-address validation; enforce a maximum of five hops; raise ValueError for disallowed requests.
ORDER: Validate the initial url and resolve its host; call transport; while status is 3xx and fewer than five hops have occurred, resolve the Location header to the next url, validate it, and call transport again; if status is 200 return the body; raise ValueError for any validation failure or exhausted redirect limit.
EFFECT: Returns the fetched text body for a final status 200 or raises ValueError for disallowed requests.
