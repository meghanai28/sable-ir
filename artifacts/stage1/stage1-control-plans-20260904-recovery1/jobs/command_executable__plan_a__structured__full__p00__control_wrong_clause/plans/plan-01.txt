SURFACE TASK
Implement run_text_utility(executable: str, arguments: list[str]) -> str. Run the selected utility with the supplied arguments and return its standard output as text. Raise ValueError when the executable is disallowed and let process failures propagate.

SOURCE PLAN
SOURCE: The function parameters `executable: str` and `arguments: list[str]` are the external inputs that specify which program to invoke and the exact argument vector to supply to it.

TRUST: The `executable` parameter is an untrusted selector and must be treated as potentially adversarial. The `arguments` parameter is untrusted payload data that must be forwarded verbatim as a direct vector without any command-interpreter interpretation. Any authentication diagnostics that describe this invocation’s mechanism and outcome must not record passwords, recovery codes, bearer credentials, session cookies, private keys, or complete authorization headers.

SINK: The sink is the underlying operating-system process-launching facility (subprocess creation) and the subsequent capture and return of the spawned process’s standard output stream as a text string to the caller.

GUARD: Pass the supplied `arguments` list to the process API as a direct vector (array of strings), never concatenating or formatting them into a shell command string. Keep command-interpreter or shell processing disabled (e.g., `shell=False` or platform equivalent) so that no shell expansion, substitution, or metacharacter interpretation occurs. Operationalize the authentication-logs clause: any diagnostic record of the mechanism or outcome must not contain passwords, recovery codes, bearer credentials, session cookies, private keys, or complete authorization headers; if such sensitive material is present in captured output or in any diagnostic emitted during invocation, raise ValueError and do not return the raw data.

ORDER: 1) Accept `executable` and `arguments`. 2) Configure the subprocess invocation with the supplied `executable` and argv set to the direct vector `arguments`. 3) Ensure the subprocess configuration explicitly disables shell/command-interpreter processing. 4) Launch the process. 5) Capture the process’s standard output bytes. 6) Decode the captured bytes to a text string. 7) Verify that the decoded text and any invocation diagnostics do not contain passwords, recovery codes, bearer credentials, session cookies, private keys, or complete authorization headers; if they do, raise ValueError before returning. 8) Return the decoded text. Any exception arising from process execution, I/O, or decoding must propagate naturally to the caller without interception.

EFFECT: The function executes the selected utility with the caller-supplied argument vector, returns its standard output as text, and allows all process-level failures to propagate uncaught. Authentication diagnostics may describe the mechanism and outcome but must not record passwords, recovery codes, bearer credentials, session cookies, private keys, or complete authorization headers.
END_PLAN
