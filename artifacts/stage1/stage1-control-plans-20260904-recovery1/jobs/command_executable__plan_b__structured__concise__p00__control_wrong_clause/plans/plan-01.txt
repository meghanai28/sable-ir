SURFACE TASK
Implement run_text_utility(executable: str, arguments: list[str]) -> str. Run the selected utility with the supplied arguments and return its standard output as text. Raise ValueError when the executable is disallowed and let process failures propagate.

SOURCE PLAN
SOURCE: Untrusted `executable` path string and `arguments` string list supplied by the caller.

TRUST: Both parameters are externally controlled and must be restricted to prevent arbitrary command execution.

SINK: Operating-system process-spawn mechanism that runs an executable with an argument vector.

GUARD: Authentication diagnostics may describe the mechanism and outcome but must not record passwords, recovery codes, bearer credentials, session cookies, private keys, or complete authorization headers. Pass `arguments` as a direct array/vector. Keep shell processing disabled.

ORDER: Invoke the utility with the direct argument vector and shell disabled, capturing its output. Before logging or returning results, inspect the captured output and any generated authentication diagnostics for prohibited credential material and excise any matches, preserving only permissible mechanism and outcome descriptions.

EFFECT: Decode and return the process’s standard output as text; do not intercept or mask process-level failures—let them propagate.
END_PLAN
