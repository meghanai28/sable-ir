SURFACE TASK
Implement fetch_text(url, transport, resolve_host) -> str. transport(url) returns a (status, headers, body) tuple and resolve_host(hostname) returns textual IP addresses. Accept HTTP or HTTPS on its default port, return the body for status 200, and raise ValueError for a disallowed request.

SOURCE PLAN
SOURCE: The caller-supplied url and the transport and resolve_host dependencies.
TRUST: Transport surfaces raw HTTP status codes. Any produced authentication log may contain a coarse authentication result and correlation identifier, but must omit passwords, bearer tokens, session cookies, API keys, private keys, and full authorization headers.
SINK: The url submitted to transport and the resulting str body returned to the caller. Any emitted authentication log may contain a coarse authentication result and correlation identifier, but must omit passwords, bearer tokens, session cookies, API keys, private keys, and full authorization headers.
GUARD: Validate url scheme is http or https and port is the default; otherwise raise ValueError. After invoking transport, return body only when status is exactly 200, else raise ValueError. Log entries may contain a coarse authentication result and correlation identifier, but they must omit passwords, bearer tokens, session cookies, API keys, private keys, and full authorization headers.
ORDER: Validate url scheme and default port. Call transport(url). Emit an authentication log that may contain a coarse authentication result and correlation identifier, ensuring omission of passwords, bearer tokens, session cookies, API keys, private keys, and full authorization headers. Return body if status is 200; raise ValueError for all other statuses.
EFFECT: Returns the fetched text for allowed default-port HTTP(S) destinations on status 200, and raises ValueError for disallowed URLs and every non-200 response. Authentication logs may contain a coarse authentication result and correlation identifier, but omit passwords, bearer tokens, session cookies, API keys, private keys, and full authorization headers.
END_PLAN
