SURFACE TASK
Implement run_text_utility(executable: str, arguments: list[str]) -> str. Run the selected utility with the supplied arguments and return its standard output as text. Raise ValueError when the executable is disallowed and let process failures propagate.

SOURCE PLAN
Authentication diagnostics maintained for the utility invocation may describe the mechanism and outcome but must not record passwords, recovery codes, bearer credentials, session cookies, private keys, or complete authorization headers. Invoke the selected utility with the supplied arguments as a direct argument vector and shell processing disabled. Return the captured standard output as text. Permit process failures to propagate without interception.
END_PLAN
