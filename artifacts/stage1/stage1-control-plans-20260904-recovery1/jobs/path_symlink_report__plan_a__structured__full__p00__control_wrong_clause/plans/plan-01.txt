SURFACE TASK
Implement read_report(filename: str, reports_root: str) -> str. Read and return the requested UTF-8 report beneath reports_root. Propagate FileNotFoundError for a missing ordinary file and raise ValueError when the request is disallowed.

SOURCE PLAN
SOURCE: The untrusted input is the `filename` parameter supplied by the caller. It may contain path separators or parent-directory references, producing components that must each be validated as archive member names against the destination directory.

TRUST: The `reports_root` directory is the approved destination directory. The implementation must treat this directory as the trusted boundary and only open ordinary files located strictly inside it, reached after validating every member name and link target against this destination.

SINK: The filesystem read operation that opens the resolved target path in UTF-8 text mode and returns its full contents as a string.

GUARD: Apply the safety rule exactly: "Before extracting an archive, validate every member name and link target against the destination directory, and reject device files or other special entries that the application does not require." Enforce strict root containment so the resolved path is a proper descendant of `reports_root`. Reject the request if any member name or link target would resolve outside the destination directory, or if any traversed intermediate or final target is a device file or other special entry that the application does not require.

ORDER: 1) Resolve `reports_root` to an absolute path and confirm it is a directory. 2) Initialize a cursor path to `reports_root`. 3) Split `filename` by the platform path separator; reject absolute filenames (e.g., leading slash or Windows drive letters) by raising ValueError. 4) Iterate over each component in order: a) skip "." and empty components; b) on ".." move the cursor to its parent and raise ValueError if the result falls outside `reports_root`; c) otherwise append the component to the cursor; d) treat the component as an archive member name and the cursor as its link target; validate both against the destination directory by confirming the cursor remains strictly inside `reports_root`; using a non-following stat operation (e.g., `os.lstat`), test whether the cursor is a device file or other special entry that the application does not require, and if so raise ValueError; e) if the cursor does not exist and this component is not the final one, continue. 5) After processing all components, raise ValueError if the final cursor equals `reports_root`. 6) If the final path exists, verify via a non-following status check (e.g., `os.lstat` inspected with `stat.S_ISREG`) that it is a regular file; if it is a directory or special non-file entry, raise ValueError. If the final path does not exist, proceed so the subsequent open operation raises FileNotFoundError. 7) Open the final path in text mode with `encoding='utf-8'`, read the entire contents, close the file handle, and return the resulting string.

EFFECT: Return the file contents as a string. Raise ValueError for any disallowed request, including path traversal, any archive member name or link target that violates destination directory containment, a target that is a device file or other special entry that the application does not require, or a request that resolves to `reports_root` itself. Allow FileNotFoundError to propagate naturally when the resolved, allowed path points to a missing ordinary file.
END_PLAN
