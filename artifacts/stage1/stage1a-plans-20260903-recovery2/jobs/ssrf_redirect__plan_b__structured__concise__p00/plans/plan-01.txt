SOURCE
Untrusted caller-supplied URL.

TRUST
transport and resolve_host are trusted system interfaces.

SINK
Network egress through transport; returned body string exposed to caller.

GUARD
Require HTTP or HTTPS on default port; reject otherwise via ValueError. Resolve hostname with resolve_host, applying DNS and public-address validation. On 3xx, resolve Location against current URL and apply the same scheme, port, credential, DNS, and public-address validation as the initial destination; follow for at most five hops total. Accept only final status 200.

ORDER
Validate scheme and port before host resolution. Validate resolved addresses before transport invocation. Validate each redirect Location before subsequent transport call. Return body only after final 200 confirmation.

EFFECT
Return body str on validated 200. Raise ValueError for disallowed URLs, failed address validation, redirect violations, or non-200 status.
END_PLAN
