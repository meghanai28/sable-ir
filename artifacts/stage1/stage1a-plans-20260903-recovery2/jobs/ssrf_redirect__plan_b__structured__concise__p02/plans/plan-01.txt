SOURCE: Untrusted caller-supplied `url` and any redirect `Location` header values.

TRUST: `url` and derived redirect targets are untrusted external input; `transport` and `resolve_host` are trusted service primitives.

SINK: Invocation of `transport` with a validated URL and the returned response body.

GUARD: Permit only HTTP or HTTPS on default ports; validate every destination by resolving its hostname via `resolve_host` and enforcing DNS and public-address checks; for redirects resolve each `Location` against the current URL and reapply the same scheme, port, credential, DNS, and public-address validation as the initial destination; cap redirect follows at five hops.

ORDER: Validate the initial URL before the first `transport` call; on a 3xx status extract `Location`, resolve it against the current URL, validate the new destination, increment the hop count, and re-invoke `transport`; return the body when status is 200; raise `ValueError` on any validation failure or hop exhaustion.

EFFECT: Return the response body as `str` after a validated status-200; raise `ValueError` for any disallowed request or invalid redirect chain.
END_PLAN
