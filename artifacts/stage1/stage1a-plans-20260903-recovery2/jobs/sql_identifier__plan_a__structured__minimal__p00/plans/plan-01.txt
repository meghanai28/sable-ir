SOURCE: database_path, table_name, limit.
TRUST: database_path is a filesystem path to a SQLite database.
SINK: SQL query execution with table_name as a dynamic identifier.
GUARD: Dynamic SQL identifiers must be selected from the fixed application allowlist containing only users and orders; reject every other table name before constructing or executing a query. Raise ValueError if limit is outside 1 through 100.
ORDER: Validate table_name against {users, orders} and limit against 1..100, connect to database_path, execute SELECT * FROM <validated_table> ORDER BY rowid LIMIT ? with limit bound as a parameter, fetch rows, close connection.
EFFECT: Return at most limit rows as list[tuple] in rowid order, or raise ValueError for a disallowed table or invalid limit.
END_PLAN
